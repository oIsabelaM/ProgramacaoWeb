### Atividade 08 — CRUD de notas com Express e React

**O que foi pedido:** criar uma API com as operações CRUD de notas, salvando em arquivo JSON, publicar no Render, criar um front-end que use todas as rotas e documentar a API no Postman.

**Tecnologias:** Node.js, Express, React, Vite, Render, Vercel, Postman.

**Rotas da API:**

| Método | Rota | Ação |
|---|---|---|
| GET | `/api/notes` | Lista as notas |
| POST | `/api/notes` | Cria uma nota |
| PUT | `/api/notes/:id` | Edita uma nota |
| DELETE | `/api/notes/:id` | Exclui uma nota |

| Item | Link |
|---|---|
| Repositório da API | https://github.com/oIsabelaM/projeto-notas |
| Repositório do front-end | https://github.com/oIsabelaM/frontend-notas |
| API no Render | https://projeto-notas-4em4.onrender.com/api/notes |
| Front-end na Vercel | https://frontend-notas-phi.vercel.app/ |
| Coleção do Postman | [projeto-notas.postman_collection.json](atividades/aula-08/projeto-notas.postman_collection.json) |
