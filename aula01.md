# 📂 Controle de Versões

## O que é?

É o processo de registrar todas as alterações realizadas em um projeto.

## Benefícios

- Recuperar versões anteriores;
- Trabalhar em equipe;
- Criar branches (ramificações);
- Organizar o desenvolvimento;
- Evitar perda de código.

## Plataformas

- GitHub
- GitLab
- Bitbucket

### Fluxo simplificado

```text
Projeto
│
├── Versão 1
├── Versão 2
└── Versão 3
```

Caso uma versão apresente erro, é possível retornar para uma versão anterior.

---

# 🚀 Deploy

Deploy é o processo de publicar uma aplicação para que outras pessoas possam utilizá-la.

## Fluxo

```text
Desenvolvedor
      │
      ▼
   GitHub
      │
      ▼
 Servidor
      │
      ▼
 Usuário acessa o sistema
```

Também foi apresentada a ideia de automação utilizando **CI/CD**, que facilita a publicação e atualização de sistemas.

# 🏗 Arquitetura de um Site

Antes de desenvolver um sistema é necessário realizar o planejamento.

## Etapas

- Definir o escopo;
- Organizar as páginas;
- Planejar a navegação;
- Validar ideias;
- Criar protótipos;
- Melhorar a experiência do usuário.

## UX e UI

### UX (User Experience)

Experiência do usuário.

Exemplos:

- Facilidade de uso;
- Organização;
- Rapidez.

### UI (User Interface)

Interface visual.

Exemplos:

- Cores;
- Botões;
- Layout;
- Tipografia.

# 💻 JavaScript (Vanilla JS)

## O que é?

JavaScript é a principal linguagem utilizada no Front-end.

Permite:

- Manipular páginas;
- Validar formulários;
- Criar animações;
- Comunicar-se com servidores;
- Tornar páginas interativas.

## Vanilla JS

É o JavaScript puro, sem utilização de frameworks ou bibliotecas.

# 🌍 Servidores, Hospedagem e CMS

## Servidor

Computador responsável por armazenar a aplicação.

## Hospedagem

Serviço que mantém a aplicação disponível na internet.

## CMS

(Content Management System)

Permite criar e administrar sites com pouca programação.

Possibilita:

- Criar páginas;
- Configurar temas;
- Instalar plugins;
- Personalizar o sistema.

---

# 🧱 Website Builders

Ferramentas para criação rápida de sites.

## ✅ Vantagens

- Fácil utilização;
- Desenvolvimento rápido;
- Templates prontos;
- Baixo custo;
- Responsividade.

## ❌ Limitações

- Pouca flexibilidade;
- Menor desempenho;
- Migração difícil.

# ⚛ Frameworks Front-end

Os frameworks facilitam o desenvolvimento da interface.

## Principais

- React
- Vue
- Angular

## Conceitos

### Componentização

Dividir a interface em pequenos componentes reutilizáveis.

```text
Página
│
├── Navbar
├── Menu
├── Conteúdo
└── Rodapé
```

Também utilizam:

- Gerenciamento de estado;
- Rotas;
- Integração com APIs.

---

# 🔧 Frameworks Back-end

Responsáveis pela lógica da aplicação.

## Principais conceitos

- MVC
- APIs REST
- Segurança
- Autenticação
- Banco de Dados

O Back-end processa informações e responde às requisições do Front-end.

---

# 🗄 Banco de Dados NoSQL

São bancos de dados que não utilizam tabelas fixas.

## Características

- Alta flexibilidade;
- Schemas dinâmicos;
- Escalabilidade;
- Armazenamento de diferentes tipos de dados.

# 📚 Resumo Geral

Ao final desta aula aprendemos que:

- Programação Web envolve a criação de aplicações para internet.
- Git é essencial para controle de versões.
- Deploy publica uma aplicação em um servidor.
- Planejamento e arquitetura são fundamentais antes da programação.
- JavaScript é a base do desenvolvimento Front-end.
- Frameworks tornam o desenvolvimento mais organizado.
- Bancos NoSQL oferecem maior flexibilidade.
- Construir um portfólio durante a disciplina será importante para avaliações e oportunidades profissionais.
