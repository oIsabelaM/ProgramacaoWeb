# Programação Web — Anotações de Estudo

Anotações das aulas 02 a 08 da disciplina de Programação Web (Prof. Me. Deivison S. Takatu), feitas a partir dos slides.

> Os trechos marcados como **Complemento** foram acrescentados às anotações (exemplos de código, tabelas e explicações) e **não estão nos slides**. O restante segue o conteúdo das aulas.

## Aulas

| Aula | Tema | Tópicos principais |
|---|---|---|
| [02](aula-02-escopo-prototipacao-ux.md) | Escopo, prototipação e UX | Tipos de aplicação web, backlog, user stories, Kanban, wireframes |
| [03](aula-03-versionamento-deploy.md) | Versionamento e Deploy | SemVer, Git, tags, branches, merge, Vercel |
| [04](aula-04-servidores-hospedagem-cms.md) | Servidores, hospedagem e CMS | Domínio, hospedagem, WordPress, temas e plugins |
| [05](aula-05-frameworks-front-end.md) | Introdução a Frameworks Front-end | Framework x biblioteca, React, Node.js, NPM |
| [06](aula-06-projetos-front-end.md) | Atividade com Projetos Front-end | Projetos em React, Angular e Vue, importação de templates |
| [07](aula-07-frameworks-back-end.md) | Introdução a Frameworks Back-end | Arquitetura, design patterns, Express.js, HTTP, REST, JSON |
| [08](aula-08-projetos-back-end.md) | Atividade com Projetos Back-end | CRUD com Express, deploy no Render, documentação com Postman |

## Comandos de referência rápida

```bash
# Git
git --version
git tag 1.0.0
git push origin 1.0.0

# React
npx create-react-app meu-projeto-react
npm start

# Angular
npm install -g @angular/cli
ng new meu-app-angular
ng serve

# Vue
npm create vue@latest
npm run dev

# Express (back-end)
npm install express
npm install cors body-parser
node server.js
```
